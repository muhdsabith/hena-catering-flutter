# HENA Catering — Flutter

Offline-first Android catering management starter with a warm cream, coffee and olive visual theme.

## Build APK
GitHub Actions is configured to build on pushes to `main` and manually from Actions → Build HENA Catering APK. Download the `hena-catering-android` artifact from a completed workflow run.

## Current foundation
Dashboard, Events, Staff, Expenses and Equipment checklist. Records are stored locally on the device with SharedPreferences.

## Next development stage
Event-wise staff roles, wages, advances, attendance, staff-linked expenses, editing/deleting records and backup/export. This is a starter foundation, not the complete app yet.
